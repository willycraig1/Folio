# Folio

A lightweight single-file browser document editor: multi-page layout, rich text, images and basic shapes, with PDF export. No install, no account, no server.

Read `FOLIO_SPEC.md` first. It defines the scope and, just as important, what Folio is **not**: no pen tool, no tracked changes, no collaboration.

## Rules
- Keep it one self-contained HTML file that runs offline.
- Stay inside the spec's scope. Raise new feature ideas with me instead of building them.

## Run
`folio.html` is the app. Open it directly in a browser. Remote: github.com/willycraig1/Folio (no GitHub Pages site).
